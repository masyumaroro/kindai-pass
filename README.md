# KINDAI PASS 試作品

近畿大学病院「通院支援アプリ アイデアコンテスト2026」で提案した「KINDAI PASS ―『次にすること』だけを、渡す。」の試作品です。

公開ページ：https://masyumaroro.github.io/kindai-pass/

## できること

- 利用登録から、どこでも受付、院内の案内、採血、待ち時間（戻る時刻）、呼び出し、診察後の会計・お薬、今日のまとめまでを通して操作できます。
- 病院側の動き（総合受付の確認、採血の呼び出し、順番の変化、お薬の準備）をこの中で再現しています。知らせが届くと、画面の「次にすること」が自動で切り替わります。
- 予約、スマート診察券、待ち状況、らくらく会計、家族、診療情報、院内マップ、交通など、今のアプリにある機能も画面として入れています。

## 個人の情報と生成AIの扱い

- 戻る時刻の予測は、内科全体の待ち人数と平均の診察時間だけで計算します。個人の情報は使いません。
- 位置情報は使いません。院内の案内は、選んだ行き先から道順を表示します。
- 生成AIの機能は初めはオフで、本人が使うと決めたときだけ動きます。このページでは外部の生成AIにはつながず、端末の中の簡易処理で代わりに動きます。

## ご注意

- 病院のシステムとはつながっていません。予約・番号・時刻・院内の配置・お薬などは、すべて架空の例です。
- 待ち時間は試作品の中で速く進めています。パソコンでは画面右側、スマートフォンでは右上の「試作品」から、速さの変更や最初からのやり直しができます。

## ファイル

- `index.html`：試作品の本体です。この1ファイルだけで動きます。
